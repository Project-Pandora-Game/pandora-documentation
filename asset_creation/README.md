# Pandora asset creation documentation

This folder contains documentation related to creating assets for Project Pandora:
- [Glossary](pages/Glossary.md), containing list of terms commonly used in relation to assets.
- [Pandora asset creation tutorial](pages/Tutorial.md), the main tutorial for getting started with assets. The tutorial also has several sub-pages:
  - [Development environment setup](pages/Tutorial_Development_environment.md)
  - [Looking at existing assets](pages/Tutorial_Existing_assets.md)
  - [Advanced topics](pages/Tutorial_Advanced.md)
- [`templates`](templates) folder, containing various images that can be used as a template for creating assets, especially for positioning details (such as rings) for cross-asset compatibility.
